## 1. 개요

### 1.1 배경
틸론소프트는 TheOtherDay 2026(제주) 행사에서 구축형 VDI 사업으로 검증한 기술을 서비스형으로 개방하는 세 가지 서비스(TheOther.Space 2.0, TheOther.Town, Kstory.ai)를 발표한다. 발표 자료는 PowerPoint가 아닌 **브라우저에서 실행되는 HTML 프레젠테이션**으로 제작하여, 배경 영상·단계별 등장·화면 간 연결 등 Apple Keynote 수준의 연출을 PC 한 대에서 안정적으로 재현한다.

### 1.2 목적
- 발표 멘트의 흐름(왜 → 무엇 → 어떻게 → 어디서)을 시각적으로 그대로 따라가는 35장의 슬라이드를 제공한다.
- 발표자가 키보드·마우스만으로 멘트 호흡에 맞춰 강조 문구를 "클릭 시 등장"시킬 수 있게 한다.
- 모든 배경 영상·이미지는 Higgsfield로 제작한 시네마틱 영상을 사용해 일관된 톤을 유지한다.

### 1.3 핵심 원칙
1. **한 장면, 한 메시지** — 슬라이드마다 강조 문구 1개를 중심에 둔다. 멘트의 나머지 내용은 보조 요소로만 표현한다.
2. **영상은 배경, 텍스트는 주인공** — 배경 영상에는 텍스트·로고를 넣지 않고, 모든 문자는 HTML로 렌더링한다(수정 용이성, 선명도).
3. **발표자가 통제한다** — 자동 재생·자동 전환은 없다. 모든 등장은 발표자의 입력으로만 일어난다.
4. **고장 나지 않는다** — 영상 로드 실패, 폰트 미로드, 창 크기 변경 상황에서도 텍스트와 네비게이션은 항상 동작한다.

## 2. 목표 및 성공 기준

| 구분 | 기준 |
|---|---|
| 기능 | 35장 모두 명세된 배경·강조 문구·클릭 스텝이 동작한다 |
| 네비게이션 | 기본 키/휠 조작과 추천 조작이 모두 동작하고 충돌이 없다 |
| 화면 | 어떤 창 크기에서도 16:9 스테이지가 왜곡 없이 중앙 정렬(레터박스)된다 |
| 성능 | 슬라이드 전환 입력 후 300ms 이내에 전환 애니메이션이 시작된다. 영상 전환 시 검은 화면(블랙 프레임)이 보이지 않는다 |
| 안정성 | 20분 연속 조작 중 브라우저 메모리 1.5GB 이하, 프레임 드롭으로 인한 끊김 없음 |
| 오프라인 | 인터넷 연결 없이 로컬 파일만으로 실행된다(외부 CDN 의존 금지) |
| 디자인 | Freesentation 9종 굵기가 역할별로 일관되게 쓰이고, 모든 텍스트가 배경 위에서 WCAG 대비 4.5:1 이상을 확보한다 |

## 3. 범위

### 3.1 포함 (In Scope)
- 16:9 가로형 HTML 프레젠테이션 1종 (단일 `index.html` + 정적 자산 폴더)
- 슬라이드 35장: 00~30 + 15-1, 15-2, 15-3, 15-4
- 배경 영상 재생(음소거 루프), 슬라이드 내 클릭 스텝(단계별 등장), 슬라이드 간 연결(05→06 BI 클릭)
- 키보드·마우스 휠·마우스 클릭 네비게이션, 전체화면, 목차 오버레이
- Higgsfield 신규 제작 영상 16종에 대한 제작 가이드(프롬프트 방향, 규격)
- 01페이지 데이터(`01.png`)의 HTML 재구성(표 + 도넛 차트)

### 3.2 제외 (Out of Scope)
- **모바일·태블릿 대응** — PC(Windows, Chrome/Edge 최신)만 지원한다. 반응형 분기, 터치 제스처는 구현하지 않는다.
- **발표자 모드** — 발표자 노트, 듀얼 모니터 뷰, 타이머는 만들지 않는다.
- 자동 재생, 음성/배경음악, 서버·DB, 로그인, 다국어
- PDF/PPTX 내보내기

## 4. 사용자 및 사용 시나리오

| 사용자 | 상황 | 니즈 |
|---|---|---|
| 발표자(1인) | 무대 PC 또는 노트북을 프로젝터·LED에 연결, 1920×1080 이상 출력 | 멘트 호흡에 맞춰 한 번의 입력으로 다음 장면을 띄운다. 실수로 두 장을 넘기지 않는다. 길을 잃으면 목차로 복귀한다 |
| 운영 스태프 | 리허설, 사전 점검 | 특정 페이지로 바로 점프, 영상 로드 상태 확인 |
| 사후 열람자 | 발표 후 파일을 받아 PC에서 열람 | 더블클릭으로 실행, 직관적 조작 |

### 주요 시나리오
1. **발표 시작** — `index.html`을 연다 → F로 전체화면 → 표지(00)에서 Space로 시작.
2. **강조 문구 등장** — 01페이지에서 83.2%를 설명한 뒤 Space(또는 클릭) → 데이터 패널이 어두워지며 강조 문구가 떠오른다.
3. **서비스 연결** — 05페이지 하단의 세 BI 중 하나를 클릭 → BI가 자리를 옮기며 06페이지로 전환된다.
4. **복귀** — 질문을 받아 16페이지로 돌아가야 할 때 `O`로 목차를 열고 썸네일 클릭, 또는 `1` `6` `Enter`로 점프.
5. **문제 상황** — 특정 영상이 로드되지 않으면 해당 슬라이드는 정적 포스터(또는 그라디언트) 위에 텍스트를 정상 표시한다.

### 5.5 네비게이션 — 기본(사용자 지정)
| 입력 | 동작 |
|---|---|
| 마우스 휠 | 1회 제스처 = 1회 "다음/이전" 이동(아래 = 다음, 위 = 이전). 스텝 규칙 F-20/F-21 적용 |
| `↓` `→` `Space` `PageDown` | 다음 |
| `↑` `←` `PageUp` | 이전 |
| `F11` / `F` | 전체화면 토글 |
| `O` | 목차 오버레이 토글 |

휠 처리 규칙: `wheel` 이벤트의 `deltaY` 부호로 방향을 결정하고, 첫 이벤트 즉시 1회 이동한 뒤 **650ms 잠금**을 건다. 잠금 중 들어오는 이벤트(트랙패드 관성 포함)는 무시한다. 잠금 해제 후에도 마지막 이벤트로부터 120ms 이내에 이어지는 이벤트는 같은 제스처로 간주해 무시한다.

### 5.6 네비게이션 — 추천 추가 항목
| 입력 | 동작 | 추천 이유 |
|---|---|---|
| 마우스 좌클릭(빈 영역) | 다음 | 프레젠터 리모컨 없이 마우스만으로 진행. 클릭 가능 요소 위에서는 제외(F-32) |
| 마우스 우클릭 | 이전. 브라우저 컨텍스트 메뉴 차단 | 좌/우 클릭 쌍으로 직관적 전후 이동 |
| `Home` / `End` | 첫 장 / 마지막 장 | 리허설 반복, 종료 후 엔딩 화면 복귀 |
| 숫자 입력 후 `Enter` | 해당 페이지로 점프(`1` `3` `Enter` → 13). 입력 중 우측 하단에 입력 숫자 표시, 2초 무입력 시 취소. 15-1~15-4는 `15.1`~`15.4`로 입력 | 질의응답 시 특정 장으로 즉시 복귀 |
| `Esc` | 오버레이(목차/도움말) 닫기 → 전체화면 해제 순서 | 표준 관례 |
| `?` (`Shift+/`) | 단축키 도움말 오버레이 토글 | 스태프·사후 열람자 학습 비용 제거 |
| `B` | 블랙아웃(화면 전체 검정) 토글. 아무 키나 누르면 복귀 | 발표 중 청중 집중 전환, 휴식 |
| `R` | 현재 슬라이드 재시작(스텝 0, 영상 0초) | 리허설 중 연출 재확인 |
| `P` | 배경 영상 일시정지/재생 | 질의응답 시 산만함 방지 |
| 화면 좌/우 가장자리 호버 | 반투명 ‹ › 화살표 버튼 표시(클릭 시 이전/다음). 커서가 떠나면 숨김 | 마우스 전용 조작자 배려 |
| 하단 진행 바 | 화면 최하단 2px 진행 바(현재 위치/전체). 마우스 이동 시 6px로 확대되고 챕터 경계 눈금 표시, 클릭하면 해당 위치로 점프 | 전체 흐름 중 현재 위치 인지 |
| URL 해시 동기화 | `#13`, `#15-2`처럼 현재 슬라이드를 해시로 반영. 새로고침·직접 링크 시 해당 장으로 복원 | 리허설 중 F5 눌러도 처음으로 튀지 않음 |
| 커서 자동 숨김 | 3초 무동작 시 커서 숨김, 움직이면 복귀 | 영상 위 커서 노출 방지 |
| 챕터 칩 | 챕터 첫 장(00, 02, 09, 12, 16, 23, 26) 진입 시 상단 중앙에 챕터명 칩이 1.5초 떠올랐다 사라짐 | 청중에게 구조 인지 제공 |
| 목차 오버레이(`O`) | 7개 챕터 × 슬라이드 썸네일 그리드. 썸네일은 각 배경 영상 첫 프레임 포스터 + 강조 문구 첫 줄. 현재 장 하이라이트, 방향키로 이동, Enter/클릭으로 점프 | 요구사항 |
