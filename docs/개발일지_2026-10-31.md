## 3. 구현 내용

### 3.1 구조

```
index.html          슬라이드 35장 본문 + 아이콘 심볼 + 크롬 + 오버레이
css/base.css        글꼴, 색상 토큰, 1920×1080 스테이지, 전환, 스텝, 크롬, 오버레이
css/components.css  타이포, 카드, 칩, 표, 도넛, 타임라인, Before/After 슬라이더 등
css/slides.css      장별 배치
js/slides.js        장 메타데이터(배경, 스텝 수, 자동 진행 간격, 목차 제목)
js/hooks.js         장별 특수 동작(카운트업, 연결선, 문턱선, 19장 슬라이더)
js/deck.js          상태·입력·전환·영상 관리 엔진
```

### 3.2 핵심 기능

- **스테이지**: 1920×1080 고정 좌표를 창 크기에 맞춰 비율 유지 확대·축소, 남는 영역은 레터박스.
- **스텝**: `data-step`, `data-dim-at`, `data-soft-at`, `data-gone-at`, `data-cls-at`, `.stagger` 속성으로 HTML만 고쳐도 연출이 바뀐다. 전체 47스텝.
- **자동 진행**: `slides.js`의 `auto:ms`가 있는 장(08·12·15-3·17·18·19·20·21)은 진입 후 스텝이 저절로 이어진다. 입력이 오면 즉시 다음 스텝으로 넘기고 이후는 다시 자동으로 진행한다.
- **영상 관리**: 현재 장과 앞뒤 1장만 `<video>`를 붙이고 나머지는 해제한다. 로드 전에는 포스터, 실패 시 대체 영상이나 그라데이션을 쓴다.
- **네비게이션**: 휠 1제스처 1이동(650ms 잠금), 방향키·Space·PageUp/Down, Shift+화살표로 스텝 건너뛰기, Home/End, 숫자 입력 점프(15.1 → 15-1), 좌·우클릭, 진행 바 클릭, 해시 링크.
- **오버레이**: 목차(O, 챕터별 썸네일), 단축키 도움말(?), 블랙아웃(B), 영상 일시정지(P), 다시 시작(R).
- **특수 연출**: 01·29 카운트업과 도넛, 04 연결선, 05 BI 카드 → 06 칩 공유 요소 전환, 07 문턱선 하강, 19 Before/After 자동 재생 슬라이더.

## 5. 문제와 해결

| 문제 | 원인 | 해결 |
|---|---|---|
| 첫 진입 시 스크립트 오류 | 이전 장 인덱스가 -1일 때 `slides[-1]` 접근 | 이전 장이 없을 때 전환 생략 |
| 중앙 정렬 요소가 스텝 등장 때 튐 | `translateY(-50%)`와 스텝 애니메이션의 `transform` 충돌 | top 기준 절대 배치로 전환 |
| `.stagger` 자식이 안 나타남 | 부모 스텝 규칙만 있고 자식 규칙 없음 | `.stagger[data-step]>*` 규칙 추가 |
| 한국어 문장이 단어 중간에서 줄바꿈 | 기본 줄바꿈 규칙 | `word-break:keep-all`, 수동 `<br>` |
| 수정이 화면에 안 보임 | 브라우저 캐시 | CSS·JS 링크에 버전 쿼리(`?v=`) |
| 해시만 바꾸면 장이 안 바뀜 | 해시 변경 미감지 | `hashchange` 처리 추가 |
| 일부 Higgsfield 제출 거부 | 자동 프리셋(IN THE DARK) 적용 | 프리셋 거절 파라미터로 재제출 |
| 영상 다운로드 SSL 오류 | 일시적 네트워크 문제 | 재시도, curl로 대체 |
| 08장 영상이 29장과 비슷 | "세 빛이 모인다" 연출이 안 나옴 | 프롬프트 두 방향으로 재생성 후 선택 |
| 수동 클릭 후 자동 진행이 멈춤 | 입력 시 타이머만 취소 | 수동 스텝 후 자동 진행 재예약 |
