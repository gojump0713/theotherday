# UI 화면설계서 — 틸론소프트 AI 서비스 소개 인터랙티브 프레젠테이션

| 항목 | 내용 |
|---|---|
| 문서 버전 | v1.0 (2026-10-31) |
| 기준 해상도 | 1920 × 1080 (16:9) 고정 좌표계. 모든 수치는 px |
| 대상 환경 | PC, Chrome/Edge 최신, 1920×1080 이상 출력. 모바일 미지원 |
| 관련 문서 | [PRD](PRD.md) |

좌표 표기: `(x, y)`는 스테이지 좌상단 기준. 와이어프레임은 1920×1080을 가로 96칸 × 세로 27줄 격자로 축약한 것이다(1칸 ≈ 20px, 1줄 ≈ 40px).

## 1. 공통 레이아웃

### 1.1 스테이지와 레이어
```
뷰포트 (임의 크기, 검정)
└─ #stage 1920×1080, transform: translate(-50%,-50%) scale(S)   S = min(vw/1920, vh/1080)
   ├─ L0  .bg-video / .bg-image      z:0   배경 미디어 (object-fit: cover)
   ├─ L1  .bg-overlay                z:1   가독성 그라디언트 (슬라이드별 --overlay 변수)
   ├─ L2  .content                   z:2   슬라이드 본문 (세이프 에어리어 내부)
   ├─ L3  .chrome                    z:3   페이지 번호, 스텝 점, 진행 바, 가장자리 화살표, 챕터 칩
   ├─ L4  .overlay-toc / .overlay-help / .blackout   z:4   오버레이
   └─ L5  .loader                    z:5   초기 로딩
```

### 1.2 세이프 에어리어와 그리드
```
┌────────────────────────────────────────────────────────────────────────────────────────────────┐ 0
│  ← 120 →                                                                              ← 120 → │
│         ┌──────────────────────────────────────────────────────────────────────────────┐       │ 80
│         │                      콘텐츠 영역 1680 × 920                                    │       │
│         │   12컬럼 그리드  /  컬럼 폭 120  /  거터 24                                      │       │
│         │                                                                              │       │
│         │                                                                              │       │
│         └──────────────────────────────────────────────────────────────────────────────┘       │ 1000
│                                                                              13 / 35  ● ● ○    │ 1040
└────────────────────────────────────────────────────────────────────────────────────────────────┘ 1080
```
- 콘텐츠 영역: `(120, 80)` ~ `(1800, 1000)`
- 12컬럼 그리드: 컬럼 120 + 거터 24 → 총 1704(마지막 거터 제외 1680)
- 기준선: 헤드라인 상단 `y=160`, 강조 문구 중심 `y=540`, 하단 보조 영역 `y=840~980`

### 1.3 크롬(공통 UI) 요소
| 요소 | 위치 | 스펙 |
|---|---|---|
| 페이지 번호 | 우하단 `(1800, 1032)` 우측 정렬 | Thin 18, `--fg-dim`. 형식 `13 / 35`, 15-1은 `15-1 / 35` |
| 스텝 점 | 페이지 번호 왼쪽 16px | 6px 원, 간격 8px. 완료 `--accent`, 미완료 `rgba(255,255,255,.3)`. 스텝 0인 슬라이드는 미표시 |
| 진행 바 | `y=1078~1080` 전폭 | 2px, 진행분 `--accent`, 잔여 `rgba(255,255,255,.12)`. 마우스 이동 시 6px로 확대 + 챕터 경계에 1×6 눈금. 호버 시 해당 위치 페이지 번호 툴팁 |
| 가장자리 화살표 | 좌 `(40, 540)`, 우 `(1880, 540)` 중심 | 64×64 원, `rgba(0,0,0,.45)` + 1px `rgba(255,255,255,.2)`. 커서가 좌/우 160px 영역에 들어오면 200ms 페이드인 |
| 챕터 칩 | 상단 중앙 `(960, 48)` | Medium 18, 패딩 8×20, 라운드 999, `rgba(255,255,255,.1)` + 블러 12. 챕터 첫 장 진입 시 1.5초 표시 후 페이드아웃 |
| 숫자 점프 입력 | 우하단 페이지 번호 위 `(1800, 996)` | Medium 28 `--accent`. 입력 중만 표시 |
| 워드마크/로고 | 00·30 전용. `THEOTHERDAY 2026` 좌상단 `(120, 72)` Thin 24 자간 0.3em / 틸론소프트 CI(W) 우상단 `(1800, 60)` 높이 44 우측 정렬 | 그 외 페이지 미표시 |

## 2. 타이포그래피

모든 글꼴은 Freesentation. 역할별 굵기 배정은 PRD 8.2와 동일하며, 여기서는 크기·행간·용도를 정의한다.

| 스타일 토큰 | 굵기 | 크기 / 행간 | 자간 | 용도 |
|---|---|---|---|---|
| `hero-num` | 900 Black | 360 / 1.0 | -0.04em | 83.2% (01, 29) |
| `cover-title` | 900 Black | 112 / 1.15 | -0.02em | 표지 타이틀 |
| `display` | 800 ExtraBold | 76 / 1.3 | -0.015em | 슬라이드 강조 문구(최대 2줄) |
| `display-s` | 800 ExtraBold | 60 / 1.35 | -0.01em | 강조 문구 3줄 이상일 때 |
| `h1` | 700 Bold | 56 / 1.3 | -0.01em | 헤드라인, 서비스명 |
| `h2` | 600 SemiBold | 40 / 1.4 | 0 | 카드 제목, 섹션 소제목 |
| `label` | 500 Medium | 24 / 1.4 | 0.02em | 칩, 라벨, 킥커(상단 작은 문구) |
| `body` | 400 Regular | 30 / 1.6 | 0 | 본문 설명 |
| `caption` | 300 Light | 22 / 1.5 | 0 | 보조 설명, 출처 |
| `question` | 200 ExtraLight | 72 / 1.4 | -0.01em | 질문형 대형 문장(16, 30) |
| `thin-mark` | 100 Thin | 24 / 1 | 0.3em | 워드마크, 페이지 번호, 배경 워터마크 |

규칙
- 강조 문구 안의 핵심 단어는 `SemiBold → Black`으로 굵기만 올리거나 `--accent` 색을 준다. 둘 다 쓰지 않는다.
- 한 슬라이드에서 `display`와 `question`을 같이 쓰지 않는다.
- 줄바꿈은 멘트의 쉼표 위치를 따른다(`<br>` 수동 지정). 자동 줄바꿈에 맡기지 않는다.
- 숫자: `font-variant-numeric: tabular-nums`.

## 3. 컬러·효과

| 토큰 | 값 | 사용 |
|---|---|---|
| `--bg` | #000 | 바탕 |
| `--fg` / `--fg-dim` | #FFF / rgba(255,255,255,.62) | 텍스트 |
| `--accent` | #22D3EE | 숫자, 밑줄, 진행 바, 완료 스텝 |
| `--accent-2` | #1C60EF | 선택·링크 상태 |
| `--space` / `--town` / `--kstory` | #4F8DFF / #A78BFA / #FBBF77 | 서비스 식별색(BI 테두리, 칩 점) |
| `--glass` | rgba(255,255,255,.06) + 1px rgba(255,255,255,.14) + blur 16 | 카드 바탕 |
| `--overlay` | 180deg, rgba(0,0,0,.25)→rgba(0,0,0,.75) | 기본 영상 오버레이 |
| `--overlay-heavy` | rgba(0,0,0,.6) 균일 + 하단 .85 | 데이터·표 슬라이드(01, 13) |
| `--overlay-light` | rgba(0,0,0,.15)→.45 | 영상이 주인공인 장(03, 09, 15) |

효과
- `dim` 상태: `opacity .35; filter: blur(2px)`.
- 발광(클릭 가능): `box-shadow: 0 0 0 1px var(--service), 0 0 32px rgba(service,.45)`.
- 텍스트 그림자: 영상 위 모든 텍스트에 `text-shadow: 0 2px 24px rgba(0,0,0,.5)`.

## 4. 공통 컴포넌트

### C1. 배경 비디오 `.bg-video`
```html
<video class="bg-video" muted loop playsinline preload="metadata" poster="assets/img/poster/13.jpg">
  <source src="assets/video/13.mp4" type="video/mp4">
</video>
```
- 슬라이드 활성 시 `currentTime=0; play()`. 비활성 500ms 후 `pause()`.
- 로드 실패 → 포스터 유지, `.bg-video.is-failed` 클래스로 Ken Burns 적용.

### C2. 강조 문구 `.display`
- 최대 폭 1440, 좌측 정렬(기본) 또는 중앙 정렬(선언형 슬라이드).
- 등장 모션 `rise`: `translateY(24px)→0`, `opacity 0→1`, 600ms, `cubic-bezier(.2,.7,.2,1)`. 두 줄이면 줄 단위 80ms 스태거.
- 핵심어 `.key`: `--accent` 색 또는 Black 굵기 + 아래 4px 밑줄이 좌→우로 그려짐(400ms, 문구 등장 후).

### C3. 스텝 컨테이너 `[data-step]`
- `data-step="n"`은 현재 스텝 ≥ n일 때 표시.
- `data-dim-at="n"`은 현재 스텝 ≥ n일 때 `dim` 처리.
- 되돌리기(이전)는 역방향으로 150ms 페이드만 수행(상승 모션 없음).

### C4. 서비스 BI 카드 `.bi-card`
```
┌──────────────────────────┐  420 × 160, --glass, 라운드 24
│ ●  TheOther.Space 2.0    │  ● 12px 서비스색 점, 이름 h2 40
│    일할 환경의 클라우드     │  caption 22 --fg-dim
└──────────────────────────┘
```
- 클릭 가능 변형 `.is-link`: 호버 시 `translateY(-4px)`, 발광, 커서 pointer.
- 공유 요소 전환: `data-flip="bi-space"` 등 식별자로 다음 슬라이드의 동일 식별자 위치까지 700ms 이동(FLIP).

### C5. 킥커 `.kicker`
- `label` 스타일, `--accent` 색, 위 또는 왼쪽에 24×2 라인. 헤드라인 위 16px.

### C6. 칩 `.chip`
- `label` 24, 패딩 10×22, 라운드 999, `--glass`. 서비스 칩은 왼쪽 8px 색점.

### C7. 흐름 화살표 `.flow-arrow`
- 48×48 SVG `→`, `rgba(255,255,255,.4)`. 카드 사이 간격 중앙에 배치. 등장 시 `scaleX 0→1`.

### C8. 비교 패널 `.compare`
- 좌/우 2열 각 780 폭, 중앙 1px 수직선 `rgba(255,255,255,.2)`. 열 상단 `label` 라벨, 아래 `h2` 또는 `body`.

### C9. 데이터 표 `.table`
- 행 높이 64, 헤더 `label` `--fg-dim`, 셀 `body` 28 tabular. 강조 행 `rgba(34,211,238,.12)` 배경 + 좌측 4px `--accent` 바.

### C10. 도넛 차트 `.donut`
- SVG 지름 420, 선 굵기 56. 세그먼트 `stroke-dasharray` 애니메이션 1.2초. 중앙 `hero-num` 축소형(120).

### C11. 목차 오버레이 `.overlay-toc`
- 배경 블러 24 + 검정 70%. 상단 `label` "목차 · O 또는 Esc로 닫기".
- 7개 챕터 행, 각 행 좌측 챕터명(`h2` 32) + 썸네일 288×162(라운드 12, 포스터 + 하단 그라디언트 + 강조문구 첫 줄 `caption`).
- 현재 장 썸네일 `--accent` 2px 테두리. 방향키로 포커스 이동, Enter/클릭 점프.

### C12. 도움말 오버레이 `.overlay-help`
- 2열 표(기본 조작 / 추천 조작). 키캡 스타일 `label` 20, 라운드 8, `--glass`.

### C13. 로딩 `.loader`
- 검정 바탕 중앙 `thin-mark` 48 "THEOTHERDAY 2026". 하단 2px 로딩 바. 최대 4초.

## 5. 모션 규칙

| 상황 | 모션 |
|---|---|
| 슬라이드 전환(다음) | 현재 콘텐츠 `opacity 1→0, translateX(0→-40px)` 350ms / 다음 콘텐츠 `translateX(40px→0), opacity 0→1` 500ms 150ms 지연. 배경 영상은 크로스페이드 600ms |
| 슬라이드 전환(이전) | 좌우 반전 |
| 점프(목차·숫자·링크) | 크로스페이드만 500ms |
| 챕터 첫 장 진입 | 배경 1.5초 동안 `scale 1.04→1.0` 추가 |
| 스텝 등장 | C2 `rise` |
| 스텝 dim | 400ms |
| 카운트업 | 83.2%는 0→83.2 1.4초 `easeOutExpo`. 금액은 0→값 1.2초 |
| 전환 잠금 | 전환 시작~완료(650ms) 동안 입력 무시 |

`prefers-reduced-motion`은 PC 발표용이므로 고려하지 않는다.

## 8. 네비게이션 상태 모델

```
상태 = { index: 0..34, step: 0..steps[index], locked: bool, overlay: none|toc|help|black }

next():
  if locked or overlay != none → 무시
  if step < steps[index] → step++ (스텝 모션)
  else if index < 34     → go(index+1, 0, 'forward')
  else                   → 무시

prev():
  if locked or overlay != none → 무시
  if step > 0            → step-- (150ms 페이드)
  else if index > 0      → go(index-1, steps[index-1], 'backward')   // 이전 장은 스텝 완료 상태

go(i, s, dir):
  locked = true; 해시 갱신(#id); 영상 마운트(i-1, i, i+1); 전환 모션; 650ms 후 locked = false
  챕터 첫 장이면 챕터 칩 표시

jump(i): go(i, 0, 'fade')      // 목차, 숫자 입력, 링크, 진행 바 클릭
```

입력 매핑 요약
| 입력 | 함수 |
|---|---|
| ↓ → Space PageDown, 휠 아래, 좌클릭(빈 영역), 우측 화살표 | `next()` |
| ↑ ← PageUp, 휠 위, 우클릭, 좌측 화살표 | `prev()` |
| Shift+→ / Shift+← | `go(index±1, 0)` / `go(index-1, 0)` |
| Home / End | `jump(0)` / `jump(34)` |
| 숫자… Enter | `jump(parse)` — `15.1`~`15.4` 허용 |
| F / F11 | 전체화면 토글 |
| O | 목차 토글 / ? | 도움말 토글 / B | 블랙아웃 토글 / P | 영상 일시정지 / R | `go(index, 0)` |
| Esc | overlay 닫기 → 전체화면 해제 |
| 05 BI 카드 클릭 | `go(6, 0, 'flip')` |
| 자동 진행 (`auto:ms`) | 08·12·15-3·17·18·19·20·21 — 진입 650ms 후 `auto` 간격으로 `step++`; 모든 입력은 타이머를 취소하고 즉시 반영 |
| 19 슬라이더 (`.no-nav`) | 진입 시 0→100→50% 자동 재생, 드래그 가능, 클릭 네비게이션 제외 |

슬라이드 id ↔ index: `00→0 … 15→15, 15-1→16, 15-2→17, 15-3→18, 15-4→19, 16→20 … 30→34` (총 35장, 스텝 총 47회).
