## 실행

가장 간단한 방법은 `index.html`을 더블클릭하는 것입니다. 영상이 많으므로 로컬 서버 실행을 권장합니다.

```bash
python -m http.server 8765 --bind 127.0.0.1
```

브라우저에서 `http://127.0.0.1:8765/` 를 열고 `F`로 전체화면을 켭니다.
특정 페이지로 바로 열려면 `http://127.0.0.1:8765/#13` 처럼 해시를 붙입니다(15-1은 `#15-1`).

## 조작

| 입력 | 동작 |
|---|---|
| 휠 아래 / 위 | 다음 / 이전 (1회 제스처 = 1회 이동, 스텝 우선) |
| `↓` `→` `Space` `PageDown` | 다음 (남은 클릭 스텝이 있으면 스텝 먼저) |
| `↑` `←` `PageUp` | 이전 (이전 장은 스텝 완료 상태로 표시) |
| `Shift`+`→` / `←` | 스텝 건너뛰고 장 이동 |
| 좌클릭 / 우클릭 | 다음 / 이전 |
| `Home` / `End` | 첫 장 / 마지막 장 |
| 숫자 입력 후 `Enter` | 페이지 점프 (`1` `3` `Enter` → 13, `15.2` → 15-2) |
| `F` / `F11` | 전체화면 |
| `O` | 목차 (방향키 이동, Enter/클릭 선택) |
| `?` | 단축키 도움말 |
| `B` | 블랙아웃 |
| `P` | 배경 영상 일시정지 |
| `R` | 현재 장 다시 시작 |
| `Esc` | 오버레이 닫기 → 전체화면 해제 |
| 하단 진행 바 클릭 | 해당 위치로 점프 |
| 05 서비스 BI 카드 클릭 | 06으로 연결 |
| 19 Before/After 슬라이더 드래그 | 낙서 ↔ 그림책 비교 (진입 시 자동 재생) |

## 자동 진행 장

08 · 12 · 15-3 · 17 · 18 · 19 · 20 · 21 은 진입 후 스텝이 자동으로 이어집니다(`js/slides.js`의 `auto:ms`).
자동 진행 중에도 클릭·키·휠로 즉시 다음 스텝/장으로 넘길 수 있으며, 입력이 들어오면 남은 자동 진행은 취소됩니다.

## 신규 영상 넣는 법

Higgsfield로 제작한 영상을 `assets/video/NN.mp4` (예: `02.mp4`, `26.mp4`) 로 저장하면 자동으로 사용됩니다.
포스터는 아래 명령으로 추출합니다.

```bash
ffmpeg -y -ss 0.5 -i assets/video/02.mp4 -frames:v 1 -vf "scale=1920:1080:force_original_aspect_ratio=increase,crop=1920:1080" -q:v 4 assets/img/poster/02.jpg
```

신규 영상 16종(02, 05~08, 10~12, 14, 24~30)은 Higgsfield Kling 3.0 Pro로 제작해 1920×1080·30fps·무음 H.264로 정규화했습니다(2026-10-31).
재생성 시 같은 파일명으로 덮어쓰면 됩니다. 파일이 깨졌을 때만 `js/slides.js`의 `FALLBACK_BG`에 적힌 보유 영상으로 대체됩니다.
